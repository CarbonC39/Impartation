# 路线图

已执行 strict 类型检查、生产构建、109 项 Node 测试和 8 项 Chromium 端到端测试；具体命令与覆盖范围见 [测试说明](testing.md)。

## 当前基础骨架与功能

- [x] npm workspaces：`apps/frontend`、`apps/backend`、`packages/shared`
- [x] Phaser 3.90 客户端与 Colyseus 0.18 权威房间
- [x] SQLite `better-sqlite3` 初始化及项目表版本迁移 v1-v3；Better Auth 表独立迁移
- [x] Tiled 大厅、默认出生点、矩形碰撞和交互区元数据
- [x] 访客昵称、三个占位头像、多人移动、房间文字聊天、20 秒重连
- [x] 留言板：SQLite 持久化，每资源最多 100 条/每条 500 字；身份作者删除自己的留言，管理员可清理其他及历史留言
- [x] 番茄钟：房间内共享 25/5 分钟计时，服务端截止时间，支持开始、暂停、继续、重置
- [x] 单元、真实 WebSocket 集成和 Chromium 端到端测试框架

- [x] 持久匿名身份与跨设备绑定：共用 Better Auth session 和资料；个人资料、作者权限及本地管理员 CLI
